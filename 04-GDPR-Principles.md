# 4. GDPR Principles 📜

The GDPR principles are the foundation of data protection.

There are **seven main principles** in Article 5.

They are:

1. Lawfulness, fairness and transparency
2. Purpose limitation
3. Data minimisation
4. Accuracy
5. Storage limitation
6. Integrity and confidentiality
7. Accountability

The European Data Protection Board describes these principles as the cornerstone of GDPR obligations and rights.

---

# 1. Lawfulness, Fairness and Transparency

## Simple meaning

You should:

```text
Process data lawfully
+
Treat people fairly
+
Explain what you're doing
```

---

## Example

MyShop collects:

```text
Email
```

It should have a valid reason for processing it and provide appropriate information about that processing.

For example:

```text
Email → Order confirmation
```

The user should not be kept in the dark about relevant processing.

---

# 2. Purpose Limitation

## Simple meaning

Collect data for:

> **Specified, explicit and legitimate purposes**

and don't simply reuse it for an incompatible purpose.

---

## Example

You collect:

```text
Address
```

Purpose:

```text
Deliver customer's order
```

Then you decide:

> "Let's sell customers' addresses to another company."

That's a different purpose and cannot simply be assumed to be allowed.

---

# Easy Question

Whenever collecting data ask:

> **WHY do I need this?**

---

# 3. Data Minimisation

## Simple meaning

Collect data that is:

> **Adequate, relevant and limited to what is necessary.**

---

## Bad Example

Newsletter form:

```text
Name
Email
Phone
Address
Passport number
Blood group
Religion
```

Why does a newsletter need all of this?

It probably doesn't.

---

## Better Example

```text
Email
```

Maybe:

```text
Name
Email
```

if the name is genuinely needed.

---

# Easy Rule

> **Need it → Collect it**
>
> **Don't need it → Don't collect it**

---

# 4. Accuracy

Personal data should be accurate and, where necessary, kept up to date.

---

## Example

Customer moves:

```text
Old address:
Ahmedabad

New address:
Vadodara
```

The application should allow the relevant information to be corrected.

Incorrect information can cause:

```text
Wrong delivery
Wrong communication
Wrong decisions
```

---

# 5. Storage Limitation

Personal data should not be kept in identifiable form for longer than necessary for the relevant purposes, subject to applicable exceptions.

---

## Example

Suppose a customer deletes an account.

The company should not simply say:

> "We'll keep everything forever."

Instead, it should have appropriate retention rules.

Some information may need to be retained for legal reasons, while other information may no longer be necessary.

---

# Easy Question

Ask:

> **"Why are we still keeping this data?"**

---

# 6. Integrity and Confidentiality

This principle is about protecting personal data.

Organizations should use appropriate technical and organizational measures to protect data.

Examples:

```text
Access controls
Authentication
Encryption where appropriate
Secure backups
Monitoring
Security testing
Least-privilege access
```

---

# Example

Bad:

```text
Customer database
        ↓
Everyone can access everything
```

Better:

```text
Customer database
        ↓
Role-based access
        ↓
Only authorized employees
```

---

# 7. Accountability

This means the organization must take responsibility for complying with GDPR and be able to demonstrate compliance.

---

## Example

Company says:

> "We protect customer data."

That's not enough by itself.

The organization should have appropriate evidence/processes such as:

```text
Privacy policies
Data inventories
Access controls
Retention rules
Security procedures
Records/documentation
Risk assessments where required
```

---

# Easy Memory Trick

Remember:

> **LEGAL → WHY → LESS → CORRECT → DELETE → PROTECT → PROVE**

| Memory  | Principle                          |
| ------- | ---------------------------------- |
| LEGAL   | Lawfulness, fairness, transparency |
| WHY     | Purpose limitation                 |
| LESS    | Data minimisation                  |
| CORRECT | Accuracy                           |
| DELETE  | Storage limitation                 |
| PROTECT | Integrity & confidentiality        |
| PROVE   | Accountability                     |

This is one of the easiest ways to remember the seven principles.
