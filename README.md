## 💡 The Main Idea

Think about GDPR like this:

> **If you collect someone's personal data, you have a responsibility to use it fairly, protect it, and respect the person's rights.**

---

## 🧠 The GDPR Question

Whenever you're building an application that handles personal data, ask:

> **Why do I need this data?**
>
> **Do I really need it?**
>
> **Am I allowed to use it?**
>
> **Is it accurate?**
>
> **How long will I keep it?**
>
> **How will I protect it?**
>
> **Can I demonstrate that I'm handling it responsibly?**

If you understand these questions, you have the foundation for understanding GDPR.
